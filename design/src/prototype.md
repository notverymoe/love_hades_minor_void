# Prototype

The gameplay prototype is a development milestone that demonstrates all of the
core gameplay mechanics, without reaching the level of polish required for a
vertical slice. It is an initial test to see if the game can function and to
determine if we can go forward with or without major adjustments to the design.

## Gameplay Systems
- Lighting
- Vision
- Object Dragging (ie. Furniture)
- Object Interaction (ie. Doors)
- Survival (ie. food, hydration, sleep, temperature, oxygen) 
- Inventory (ie. pickup, place, transfer)
- Mini-games
- Crafting 
- Economy (ie. Buy, Sell, Work)
- Cleaning
- Time (ie. Day, Deadlines)
- Dialogue
